# Contributing to Minflair

First off, thank you for considering contributing to Minflair! It's people like you that make the Linux community such a great place.

## How Can I Contribute?

### Reporting Bugs
Bugs are tracked as GitHub issues. When creating an issue, please use the **Bug Report** template and provide as much context as possible, including your system information and steps to reproduce.

### Suggesting Enhancements
Enhancement suggestions are also tracked as GitHub issues. Please use the **Feature Request** template and detail exactly how the enhancement would work and why it would be useful.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Ensure your UI changes follow the current styling conventions in the Quickshell components.
3. Test your changes locally to ensure they don't break existing functionality.
4. Issue that pull request! Please use the provided Pull Request template and fill it out completely.

## Code Style Guidelines
- **QML**: Keep components modular. If you are creating a generic UI element (like a button or a slider), place it in `config/quickshell/Core/Components`. Keep backend logic in `Core/Services`.
- **Scripts/Lua**: Keep code clean, well-commented, and use the existing conventions.

Thank you for helping make Minflair better!
